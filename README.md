# Energy Shield Lab

대전 대화동 노후 산업단지에 쿨루프와 태양광을 설치하는 정책의 경제적·환경적 효과를 비교하는 **내부 연구용 시뮬레이터**입니다. 학생이 계산 원리와 정책 효과를 직접 검증하기 위한 도구입니다.

- 공모전 제출물을 자동으로 만들지 않으며, 사업 타당성의 근거가 아닙니다.
- 기본값은 연습용입니다. 많은 값이 출처 없는 임의 가정입니다. 대화동 공장을 조사한 값은 없습니다.
- 관측값을 미리 넣어 두지 않았습니다. 측정 기록은 직접 입력하기 전까지 비어 있습니다.
- 로그인과 외부 API가 없고, 데이터는 브라우저의 `localStorage`에만 저장합니다.

## 실행

```bash
npm install
npm run dev      # http://127.0.0.1:3000
npm test         # 단위 테스트
npm run lint
npx tsc --noEmit
npm run build && npm start   # 프로덕션 빌드 실행
```

Next.js 자체의 익명 사용 통계까지 끄려면 `npx next telemetry disable`을 한 번 실행하세요. 앱 기능과는 관계가 없습니다.

## 데이터의 세 종류

| 종류 | 표시 | 저장 위치 |
|---|---|---|
| 가정 기반 추정 | 점선 테두리, "가정 기반 추정 · 측정값 아님" | 입력값 키, 실행 기록 키 |
| 가상 공장 데이터 | 점 테두리와 어두운 배경, "가상 공장 데이터 · 실제 공장 아님" | 저장하지 않고 시드로 다시 만듦 |
| 사람 측정 | 굵은 실선, 꽉 찬 배지 "사람 측정" | 측정 기록 키 (`lib/measurements.ts`는 계산 엔진을 가져오지 않음) |

측정값은 계산에 자동 반영되지 않습니다. "기본값으로"를 눌러도 측정 기록, 실행 기록, 연구 메모는 지워지지 않습니다.

## 계산 논리

모든 값은 **면적 → 용량 → 전력량 → 비용·탄소** 순서로 이어집니다.

### 1. 설치 유형

| 유형 | 쿨루프 시공 면적 | 효과 인정 면적 | 태양광 면적 |
|---|---|---|---|
| C-1 쿨루프 단독 | 전체 지붕 | 전체 지붕 | 0 |
| C-2 태양광 단독 | 0 | 0 | 전체 × 설치 가능 비율 |
| A 분리 설치형 | 전체 − 태양광 면적 | 시공 면적과 같음 | 전체 × 설치 가능 비율 |
| B 전체 쿨루프 + 태양광 | 전체 지붕 | 전체 − 태양광 면적 | 전체 × 설치 가능 비율 |

같은 면적에 쿨루프와 태양광을 함께 설치하는 것은 물리적으로 가능합니다. 다만 패널 아래 지붕은 그늘과 공기 흐름, 복사가 달라 노출 지붕과 같은 효과를 낸다고 볼 수 없습니다. 고반사 지붕에 패널을 놓으면 실내 열 획득이 10.8% 늘었다는 수치 모델 연구도 있어([Ma 외, Solar Energy 2023](https://orbit.dtu.dk/en/publications/shading-effect-and-energy-saving-potential-of-rooftop-photovoltai/), 우한), 유형 B는 패널 하부의 효과를 **미산정**합니다. 미산정은 효과가 0이라는 뜻이 아닙니다. 유형 B의 비용에는 패널 하부 시공비가 포함됩니다.

### 2. 에너지와 전력 흐름

```
태양광 용량(kW)         = 태양광 면적(m²) × 용량 밀도(kW/m²)
태양광 총발전량(kWh/년)  = 용량(kW) × 연간 발전량(kWh/kW·년)
자가소비량(kWh/년)       = 총발전량 × 자가소비 비율
역송량(kWh/년)          = 총발전량 − 자가소비량
냉방 절감량(kWh/년)      = 전체 지붕 × 냉방 기준값 × 절감률 × (효과 인정 면적 ÷ 전체 지붕)
전력망 구매 감소(kWh/년) = 냉방 절감량 + 자가소비량
```

### 3. 비용

```
총사업비(원)    = 쿨루프 시공 면적 × 쿨루프 단가 + 태양광 용량 × 태양광 단가
대전시 부담(원)  = 총사업비 × 지원율
소유주 부담(원)  = 총사업비 − 대전시 부담
```

### 4. 온실가스

```
감축량(tCO2eq/년) = (전력망 구매 감소 + 역송량 × 역송 인정 비율) ÷ 1,000 × 배출계수
```

각 kWh는 구매 감소 또는 역송 중 한 곳에만 들어가므로 중복 계산되지 않습니다. 역송 인정 비율이 100%이면 자가소비 비율은 감축량을 바꾸지 않고 구매 감소량만 바꿉니다.

- **평균 배출계수:** 전력망 전체 배출량 ÷ 전체 전력량. 기본값 0.4173은 2023년도 값으로 언론 보도 2곳에서 확인했지만 부처 원문을 열어 보지 못해 **검증 전 참고값**으로 표시합니다.
- **한계 배출계수:** 수요 변화에 실제로 반응하는 발전기의 배출 강도. 믿을 만한 한국 값을 찾지 못해 기본값을 비워 두었고, 비우면 **미산정**입니다.
- 설비 제조·운송·폐기 배출은 포함하지 않습니다.

### 5. 지원율 분석은 두 가지입니다

- **사업 규모 고정:** 지원율은 누가 내는지만 바꿉니다. 총사업비, 면적, 발전량, 감축량은 그대로입니다.
- **대전시 예산 고정:** `지원 가능 공장 = min(전체 공장, ⌊예산 ÷ 공장당 대전시 부담⌋)`. 지원율이 물리적 효과를 바꿉니다. 단, 참여 의사는 계산하지 않습니다.

70%는 정책 제안값이며 실제 운영 중인 제도가 아닙니다.

### 6. 예산 최적화 (0-1 정수계획법)

```
최대화  Σ 감축량ᵢ · xᵢ
조건    Σ 대전시 부담ᵢ · xᵢ ≤ 예산,  xᵢ ∈ {0, 1},  구조 부적합이면 xᵢ = 0
```

파레토 동적계획법과 선형완화 가지치기로 풉니다. 끝까지 돌면 **정확한 최적해**이고, 상태가 300만 개를 넘으면 멈추고 **근사해**로 표시합니다. 무작위·면적 순·효율 순 선정과 같은 예산, 같은 후보로 비교합니다. 공장은 시드로 만든 가상 데이터이므로, 결과는 실제 공장에서의 우위를 증명하지 않습니다.

### 7. 민감도

- **단일 변수:** 한 번에 하나만 낮은 값·높은 값으로 바꾸고, 결과 변동 폭으로 순위를 매깁니다.
- **동시 변수:** 고른 변수의 조합(2^k개)을 모두 계산해 최솟값과 최댓값을 찾습니다.

범위는 사용자가 정한 가정이며 **통계적 신뢰구간이 아닙니다.** 순위는 범위에 따라 달라집니다.

### 8. 측정 기반 분석 (모드 2)

반복 측정의 평균, 표본표준편차(n−1), 시공 전후 평균 차이를 계산합니다. 결측은 0으로 바꾸지 않고 통계에서 뺍니다. 외기 온도나 일사량의 전후 기록이 없으면 경고합니다. **온도 차이를 연간 냉방 전력 절감률로 자동 변환하지 않습니다.**

## 손으로 검산한 예 (유형 A)

공장 10개, 지붕 1,000m², 설치 가능 50%, 밀도 0.1kW/m², 발전량 1,000kWh/kW, 냉방 기준값 20kWh/m², 절감률 10%, 쿨루프 10,000원/m², 태양광 100만 원/kW, 지원율 25%, 자가소비 80%, 역송 인정 100%, 배출계수 0.5.

| 단계 | 계산 | 결과 |
|---|---|---|
| 태양광 면적 | 10,000 × 50% | 5,000m² |
| 쿨루프 면적 | 10,000 − 5,000 | 5,000m² |
| 용량 | 5,000 × 0.1 | 500kW |
| 총발전량 | 500 × 1,000 | 500,000kWh |
| 자가소비 / 역송 | 80% / 20% | 400,000 / 100,000kWh |
| 냉방 절감량 | 10,000 × 20 × 10% × 50% | 10,000kWh |
| 구매 감소 | 10,000 + 400,000 | 410,000kWh |
| 총사업비 | 5,000 × 10,000 + 500 × 1,000,000 | 5억 5,000만 원 |
| 대전시 / 소유주 | 25% / 75% | 1억 3,750만 원 / 4억 1,250만 원 |
| 감축량 | (410,000 + 100,000) ÷ 1,000 × 0.5 | 255tCO2eq |

## 정책 시뮬레이션 절차

1. **유형 비교** 탭에서 왼쪽 입력값을 자료가 있는 값으로 바꾸고 "출처와 가정"에서 각 값의 근거 수준을 확인합니다.
2. 왼쪽 위에서 분석할 설치 유형을 고릅니다.
3. **지원율·예산** 탭에서 사업 규모 고정 분석과 예산 고정 분석을 비교합니다.
4. **예산 최적화** 탭에서 예산과 시드를 바꿔 선정 방식을 비교합니다.
5. **민감도** 탭에서 범위를 정하고 어느 가정이 결과를 가장 흔드는지 확인합니다.
6. **실측 분석** 탭에 실제로 측정한 값만 기록합니다.
7. **실행 기록·연구 노트** 탭에서 실행 기록을 만들고, 재현 확인을 본 뒤 JSON/CSV로 내보내고, 연구 목적과 해석을 직접 작성합니다.

## 이 모델이 계산하지 않는 것

- 패널 그늘과 쿨루프의 상호작용, 쿨루프가 패널 온도나 양면 패널 발전량에 미치는 영향
- 겨울 난방 전력 증가(겨울철 불이익)
- 층수, 단열, 설비, 조업 시간의 차이
- 시간대별 수요·발전 일치. 자가소비 비율은 입력값 그대로이며 공장 사용량을 넘는지 확인하지 않습니다.
- 설비 제조·운송·폐기 배출, 전력망 탈탄소화에 따른 계수 변화
- 유지보수, 패널 교체, 구조 보강, 전기요금 절감, 수익
- 공장의 참여 의사 ([2024년 산업단지공단 조사](https://www.asiae.co.kr/en/article/2024100709355316824): 응답 기업의 60.5%가 지원을 늘려도 설치 의향 없음)
