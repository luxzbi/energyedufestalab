# Energy Shield Lab

대전 산업단지 지붕에 쿨루프와 태양광을 적용하는 정책 제안의 **계산 논리를 배우기 위한** 로컬 프로토타입입니다.

- 공모전 제출물이나 사업 타당성 근거가 아닙니다.
- 기본값은 연습용입니다. 일부는 출처 없는 임의의 값입니다.
- 관측값을 미리 넣어 두지 않았습니다. 측정 기록은 직접 입력하기 전까지 비어 있습니다.
- 로그인과 외부 API가 없고, 데이터는 브라우저의 `localStorage`에만 저장합니다.

## 실행

```bash
npm install
npm run dev      # http://127.0.0.1:3000
npm test         # 단위 테스트
npm run build && npm start   # 프로덕션 빌드 실행
```

Next.js 자체의 익명 사용 통계까지 끄려면 `npx next telemetry disable`을 한 번 실행하세요. 앱 기능과는 관계가 없습니다.

## 계산 논리

모든 값은 **면적 → 용량 → 전력량 → 비용·탄소** 순서로 이어집니다.

### 1. 시나리오는 "어느 면적에 무엇을 설치하는가"로 나뉩니다

| 시나리오 | 쿨루프 면적 | 태양광 면적 |
|---|---|---|
| 쿨루프 단독 | 전체 지붕 | 0 |
| 태양광 단독 | 0 | 전체 지붕 × 설치 가능 비율 |
| 결합 | 전체 지붕 − 태양광 면적 | 전체 지붕 × 설치 가능 비율 |

전체 지붕(m²) = 공장 수 × 평균 지붕 면적

**결합은 두 단독 시나리오의 합이 아닙니다.** 패널이 덮은 곳은 햇빛을 직접 받지 않으므로 쿨루프를 칠하지 않는다고 가정합니다. 그래서 설치 가능 비율이 100%면 결합은 태양광 단독과 같고, 0%면 쿨루프 단독과 같습니다. 이 규칙은 테스트로 검증합니다.

### 2. 에너지

```
태양광 용량(kW)        = 태양광 면적(m²) × 용량 밀도(kW/m²)
태양광 발전량(kWh/년)  = 용량(kW) × 연간 발전량(kWh/kW·년)
절감 냉방 전력(kWh/년) = 전체 지붕(m²) × 냉방 기준값(kWh/m²·년) × 절감률 × (쿨루프 면적 ÷ 전체 지붕)
```

냉방 기준값과 절감률은 **모두 가정**입니다. 따라서 절감 냉방 전력도 측정 결과가 아니라 가정의 곱입니다.

### 3. 비용

```
총사업비(원)   = 쿨루프 면적 × 쿨루프 단가(원/m²) + 태양광 용량 × 태양광 단가(원/kW)
지자체 부담(원) = 총사업비 × 보조율
소유주 부담(원) = 총사업비 − 지자체 부담
```

보조율은 비용을 나눌 뿐이라 총사업비와 CO2 감축량을 바꾸지 않습니다.

### 4. 탄소

```
CO2 감축량(tCO2eq/년) = (절감 냉방 전력 + 발전량)(kWh) ÷ 1,000 × 배출계수(tCO2eq/MWh)
```

÷ 1,000은 kWh를 MWh로 바꾸는 단계입니다. 단위를 맞추지 않으면 결과가 1,000배 어긋납니다.

### 손으로 검산한 예

공장 10개, 지붕 1,000m², 설치 가능 50%, 밀도 0.1kW/m², 발전량 1,000kWh/kW, 냉방 기준값 20kWh/m², 절감률 10%, 쿨루프 10,000원/m², 태양광 100만 원/kW, 보조율 25%, 배출계수 0.5일 때의 결합 시나리오입니다.

| 단계 | 계산 | 결과 |
|---|---|---|
| 태양광 면적 | 10,000 × 50% | 5,000m² |
| 쿨루프 면적 | 10,000 − 5,000 | 5,000m² |
| 용량 | 5,000 × 0.1 | 500kW |
| 발전량 | 500 × 1,000 | 500,000kWh |
| 절감 냉방 전력 | 10,000 × 20 × 10% × 50% | 10,000kWh |
| 총사업비 | 5,000 × 10,000 + 500 × 1,000,000 | 5억 5,000만 원 |
| 지자체 / 소유주 | 25% / 75% | 1억 3,750만 원 / 4억 1,250만 원 |
| CO2 감축량 | 510MWh × 0.5 | 255tCO2eq |

## 이 모델이 계산하지 않는 것

- 건물별 단열, 층수, 설비 차이: 절감량이 면적에 비례한다고 단순화했습니다.
- 패널 그늘의 냉각 효과, 쿨루프가 패널 온도나 양면 패널 발전량에 미치는 영향
- 쿨루프로 늘어날 수 있는 겨울 난방 전력
- 자가소비와 전력망 역송의 차이: 모두 전력망 전기를 대체한다고 가정합니다.
- 전력망 평균 배출계수와 실제로 줄어드는 발전원 배출의 차이, 설비 제조 과정의 배출
- 유지보수, 패널 교체, 구조 보강, 전기요금 절감, 수익

## 가정 계산과 측정값의 구분

| | 가정 계산 | 사람 측정 |
|---|---|---|
| 화면 표시 | 점선 배지 "가정 계산 · 측정값 아님" | 꽉 찬 배지 "사람 측정" |
| 코드 | `lib/model.ts` | `lib/measurements.ts` (계산 엔진을 가져오지 않음) |
| CSV | 계산 결과 파일, `데이터 구분` 열에 표시 | 측정 기록 파일, `데이터 구분` 열에 표시 |

측정값은 계산에 자동 반영되지 않습니다. 측정값으로 가정을 바꾸려면 측정 방법과 표본을 먼저 검토한 뒤 사람이 직접 입력값을 고쳐야 합니다. "기본값으로"를 눌러도 측정 기록은 지워지지 않습니다.

## 코드 구조

| 파일 | 역할 |
|---|---|
| `src/lib/model.ts` | 계산 엔진. 화면과 분리된 순수 함수 |
| `src/lib/fields.ts` | 입력 항목 정의(단위, 범위, 출처)와 입력 검증 |
| `src/lib/formulas.ts` | 계산 과정을 사람이 읽는 풀이로 변환 |
| `src/lib/measurements.ts` | 측정 기록 검증과 요약 |
| `src/lib/csv.ts` | CSV 생성(엑셀 수식 실행 방지, 한글 BOM) |
| `src/lib/storage.ts` | localStorage 읽기·쓰기, 손상된 측정 기록 백업 |
| `src/components/` | 화면 구성요소 |

출처와 각 기본값의 신뢰 수준은 앱의 "출처와 가정" 구역과 `src/lib/fields.ts`에 있습니다.
